How this works

You are editing the real files in tools/replay/prompts/. Save writes straight to disk — Claude picks changes up by reading the files, so every save is visible to the replay loop immediately. Add a new prompt by duplicating text into a new tab via Finder (new .txt in the folder, then reopen).

Browser can't edit local files

This page needs the File System Access API (Chrome/Edge/Arc on macOS). Open it in Chrome, or edit the files directly at ~/Projects/voice-dispatch/tools/replay/prompts/ — they're plain text and every save is picked up the same way.
